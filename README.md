# Portfolio

David Lê's personal portfolio site — an infinite pannable/zoomable canvas
styled like a bullet journal. See `CLAUDE.md` and `docs/SPEC.md` for the
full project vision, tech stack decisions, and milestone roadmap.

## Development

```bash
npm install
npm run dev
```

## Stack

- Vite + React + TypeScript
- Canvas: `react-zoom-pan-pinch`
- Framer Motion for supporting animation
